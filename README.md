## 使用提示词

1. 打开作品的提示词页面，复制 **Prompt** 下的内容。
2. 粘贴给运行 Kimi K3.1 Pro 的 Agent。
3. 根据作品需要生成动画或场景，预览并导出视频。

部分创作者只分享了提示词片段，或只在原帖中描述作品，对应页面会注明。
